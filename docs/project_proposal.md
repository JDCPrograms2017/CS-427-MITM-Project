# Wireless Hijacking Man-in-the-Middle Attack

## Abstract and Motivation
Our team aims to demonstrate a successful de-authentication attack on a device within an isolated network environment. Following this, we will attempt to insert ourselves into the middle of wireless communication using an Evil Twin access point equipped with packet sniffing capabilities.

Our approach includes:
- Deploying an unencrypted rogue access point to bypass handshake requirements
- Optionally implementing a captive portal attack to mimic a legitimate login page and capture user credentials

This project explores vulnerabilities in modern wireless protocols. Given the widespread use of WiFi across billions of devices, understanding weaknesses in current standards is critical. For educational purposes, we may simulate attacks on older or downgraded systems (e.g., unencrypted or WPA2 networks), while still achieving the same learning objectives.

---

## Project Outcomes
- Successful de-authentication attack on a vulnerable device
- Functional Evil Twin capable of tricking devices into connecting
- Capture of sensitive user information via:
  - Unencrypted access point, or
  - Captive portal attack
